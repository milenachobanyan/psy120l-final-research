# Relationship Pursuit Study
This project examined how relationship context and commitment readiness influence romantic partner trait preferences. Specifically, it tested whether being assigned to a long-term vs. short-term relationship condition affected how much participants valued warmth traits versus attractiveness traits in a potential partner, and whether this effect depended on commitment readiness.
The report was created using Quarto and R.
The published report file is index.html.
The dataset is not included in this repository.
